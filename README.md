# hello-claude-pr

A tiny practice repo for shipping a first pull request with Claude Code.

## What this is

This repo exists to walk through the full PR workflow: branch, commit, push,
open a PR, and merge — with a small, safe change.

## Try it yourself

1. Clone the repo
2. Create a branch
3. Make a small change
4. Open a pull request
